The 44 count includes imported tests executed by multiple test roots. Gates:
`zig build verify --summary all`, then with `-Doptimize=ReleaseSafe`,
`zig build -Doptimize=ReleaseSafe`, `python3 tests/integration.py`, and
`python3 tools/smoke.py`. The Linux wrapper streams into a validated temporary
directory, requires exact Zig and uses 180-second build watchdogs. Its archive
omits .git, so the enclosing clean-tree commit identifies the source even though
the embedded smoke client cannot independently query a remote checkout.

Integration has a 90-second suite watchdog, eight-second child shutdown bound
and shorter fixture deadlines. It tests four simultaneous exact 1024-byte bodies
at a four-slot cap, refuses an extra connection, then validates all echoes and
recovery. Every phase ended with zero owned connections/operations, zero late
framework allocations, and heap peak within its configured requested-byte cap.

The final slow-reader test received a 2 MiB echo request and deliberately did
not drain output, with requested SO_SNDBUF4096 and client SO_RCVBUF1024. It sent
only 524,765 total bytes on Mac / 66,013 on Linux before timing out, and only
the two healthy controls completed. An earlier Linux fixture allowed the kernel
to absorb the entire echo and only proved an idle keep-alive deadline; the
strengthened witness explicitly rejects that interpretation.

All timing below uses **ReleaseSafe**, verified from the running binary's READY

10,000 responses each, eight clients, two application workers and 128-slot
capacity. There is no warmup/repetition, saturation search, separate load host
or competitor. Do not infer server capacity or an architecture ranking.
