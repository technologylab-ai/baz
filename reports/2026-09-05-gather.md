# Buffered gather-send experiment — 2026-09-05

Sending buffered header and body together raised pipeline-16 throughput from
**124,505 to 344,394 responses/s**, **2.77×**, in the same inline-mode sweep.
Worker/scalar median was 109,178 and libreactor 3,795,163. This is a substantial
reduction in transport dependencies, but still leaves an approximately 11× gap
to the three-process contender. Response batching remains a distinct next step.

## Mechanism and reliability

The header was already in a buffer; the old scalar path submitted its span,
waited for completion, submitted the body, then waited again. The new gather
path copies only at most five slice descriptors into stable startup iovec/
msghdr metadata. Linux submits SENDMSG, while Mac uses nonblocking sendmsg
through kqueue readiness. It does not copy borrowed payload bytes. Metadata
and payloads stay live until the target's terminal completion, independently
of a cancel request's acknowledgement. The aggregate send_chunk/i32 byte cap
and cursor advancement cover completions before, at, or after span boundaries.

The default is now **inline with zero application workers and gather enabled**.
Blocking application callbacks must explicitly choose worker mode. /stall is
unavailable inline; an arbitrary violating callback still cannot be preempted.
`--gather-send 0` preserves the scalar diagnostic path.

Exact Zig 0.16.0 Mac Debug and ReleaseSafe each passed 49 unit test executions.
Mac and Linux ReleaseSafe passed 26 worker wire, 10 inline, and 11 gather cases;
Mac Debug also passed 11 gather cases. Both native hosts directly witnessed
**two scalar completions becoming one two-vector gather completion** for
plaintext in both execution modes. Mac's slow-reader fixture recorded 128 actual
short gather completions, one pending gather cancel and one canceled terminal
completion, then zero retained owners and healthy-request recovery. Linux has
its own packet; counts must not be copied between platforms.

The separate Linux transport cross-compilation performed before native execution
is retained as compile-only evidence. Source tests inject short positive cursor
advances; wire send_chunk cases cap submitted bytes and do not by themselves
prove kernel short completions. Native slow-reader counters provide that witness.

The generic bounded response-batching experiment follows separately. This report
does not claim requests were already batched, completion lookup was constant
time, or multiple I/O owners existed at this checkpoint.
